# LEIF — Longitudinal Environmental Interaction Footprint

## Project Overview
LEIF is a Computer Vision project designed to analyze long-duration videos and organize observed interactions between people and objects over time. It aims to provide a structured event history and visualize interaction patterns through an interactive dashboard.

## Objectives
- Analyze video input using Computer Vision techniques.
- Track observable people and objects.
- Organize detected events chronologically.
- Visualize interaction patterns and environmental changes.
- Present analysis through an interactive dashboard.

## Key Features
- Video upload and processing
- Object detection and tracking
- Event history and timeline visualization
- Interaction graphs and analytics
- Environmental interaction heatmaps
- Summary of observed events

## Technologies Used
- Python
- OpenCV
- HTML, CSS, and JavaScript
- Machine Learning and Computer Vision libraries
